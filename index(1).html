就像是系统应用一样简单

// 像调用系统 API 一样，直接访问更高权限的能力
private static final IPackageManager PACKAGE_MANAGER =
    IPackageManager.Stub.asInterface(
        new PaperLiteBinderWrapper(
            SystemServiceHelper.getSystemService("package")));

public static void grantRuntimePermission(String pkg, String permission, int userId) {
    try {
        PACKAGE_MANAGER.grantRuntimePermission(pkg, permission, userId);
    } catch (RemoteException e) {
        throw new RuntimeException(e.getMessage(), e);
    }
}

简介

PaperLite 可以帮助普通应用借助一个由 app_process 启动的进程，直接使用更高权限的系统能力，无需 root shell。

PaperLite 为何而生？

它的诞生主要有两个目的：

  • 提供一个方便地使用系统能力的方式
  • 为部分只需要 adb 权限的应用开发提供便利

与「传统」做法对比

「传统」做法

以启用 / 禁用组件为例，一些需要 root 权限的应用会直接在 su 中执行 pm disable。

  • 执行 su，再执行 pm disable
  • 每一次「执行」都意味着新进程建立，大量时间和性能消耗在进程创建上
  • 极慢，且需要处理文本才能拿到结果
  • 功能受制于可用指令，即使 adb 权限足够也往往需要 root

PaperLite 做法

PaperLite 会引导用户以 root 或 adb 方式运行一个服务进程。应用通过这个进程与系统交互，几乎不产生额外开销。

  • 极小的额外时间及性能消耗
  • 与直接调用 API 的体验几乎一致
  • 不需要 root 也能覆盖更多设备

用户手册

整个流程不需要数据线，也不需要电脑。首次使用唯一要做的，是在系统设置里打开无线调试。

01 · 打开无线调试

设置 → 开发者选项 → 无线调试。系统要求 Android 11 及以上；PaperLite 本身支持 Android 10+，低版本可手工填端口。

02 · 在 PaperLite 里配对

进入「配对」页搜索服务端口，手动输入配对码，或用识别按钮自动读取。

03 · 开始操作

通道自动就绪。装包、卸应用、跑命令，直接在对应页面里做。需要高权限的操作会按优先级自动挑一条能用的通道执行，并告诉你走了哪条路。

 遇到问题设置页有「上次异常退出」，里面是完整崩溃堆栈，复制出来就能定位。
